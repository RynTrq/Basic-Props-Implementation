# React Job Cards — Props and Components

A small React interface demonstrating reusable job-card components and data passed through props.

The displayed company names and openings are sample interface data, not a live jobs feed.

## Run locally

```bash
git clone https://github.com/RynTrq/Basic-Props-Implementation.git
cd Basic-Props-Implementation
npm ci
npm run dev
```

Open the local Vite address. Use `npm run build` to create a deployment build and `npm run lint` to run the configured checks.

## Source guide

- `src/App.jsx` — sample records and card composition.
- `src/components/Card.jsx` — reusable card component.
- `src/App.css` and `src/index.css` — presentation styles.
